# Attendance Management System
## 1. Requirement Analysis
The system is designed to:
- Accept student name
- Accept attendance status (Present or Absent)
- Display attendance record

## 2. System Design
  - Programming Language: Python
  - input: student_name, attendance_status
  - Processing: None (direct recording)
  - Output: Attendance record display

## 3. Implementation
The system was implemented using python.
The file 'attendance_management_system.py' contains the implementation.
The variable names used in the design match those used in the code.

## 4. Testing
The system was tested using:
- Name: John, Status: Presnt
- Name: Mary, Status: Absent

The system displayed correct attendance records.

## 5. Deployment
The system was deployed by uploading it to GitHub.

## 6. Maintenance
Future improvements include:
- Recording multiple students
- Storing attendance records in a file
- Adding date and time tracking
